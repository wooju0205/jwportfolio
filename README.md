# Jady Woo — Personal Portfolio Website

Interactive, responsive, and lightweight personal portfolio website built with clean vanilla HTML, CSS, and JavaScript. Inspired by modern vintage aesthetics, interactive Mac Finder interface, and paper craft details.


---

## ✨ Key Features

- **Interactive Finder / File Explorer:** A desktop-inspired Finder workflow allowing visitors to expand folders and explore projects interactively.
- **Wax-Sealed Envelope Contact Form:** Interactive envelope animation integrated with direct email delivery via Web3Forms API.
- **Responsive & Accessible Design:** Fully responsive layout with smooth transitions, custom Hanji-grain texture, and `prefers-reduced-motion` support.

---

## 🛠️ Built With

- **HTML5** — Semantic structure & accessibility
- **CSS3** — Custom properties, CSS Grid/Flexbox, dynamic animations
- **JavaScript (ES6+)** — DOM manipulation, async/await fetch, interactive folder UI
- **Web3Forms API** — Secure, client-side contact form delivery
